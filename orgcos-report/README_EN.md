## Overview

OrgCOS report generation tool creating single-file HTML visualization reports from OrgCOS data. Supports 4 report types (Panorama overview, Domain Deep-dive, Quality Audit, Org Portrait) following brand standards (#074973/#0A6B8C/#04314f/#35a7d6) with sidebar navigation and fluid content layout. Use when the user mentions OrgCOS report, panorama, quality report, or org portrait report.
