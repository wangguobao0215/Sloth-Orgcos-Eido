# Changelog

All notable changes to the OrgCOS skill family are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-03

### Changed
- Renamed all 12 skills from `orgcos-*` to `sloth-orgcos-*-eido` per Sloth-Eido Family Convention.
- Repo name: `Sloth-Orgcos-Eido` (树懒 · 组织认知).

### Added
- Initial release of 12 orgcos-* skills.
- orgcos-architect: master orchestrator (8-phase P0-P7 workflow).
- orgcos-kernel: T1 universal kernel (Schema, Entity-Relation, Governance, API specs).
- orgcos-ontology: L1 Ontology + L4 Semantics collection.
- orgcos-strategy-ops: L2 Strategy + L3 Operations collection.
- orgcos-memory-char: L5 Memory + L6 Character collection.
- orgcos-governance: Governance engine (G1-G5 rules, 12-field validation).
- orgcos-seci: SECI knowledge conversion engine (8-week spiral).
- orgcos-blueprint: T2 industry blueprint manager.
- orgcos-validator: quality validation tool (3-dimension checks).
- orgcos-api: AI consumption API standardization (4 endpoints + SDK).
- orgcos-report: report generation tool (4 HTML report types).
- orgcos-pipeline: orchestration engine (skill dispatch + error recovery).
- Kernel config files: context-entry.schema.json, governance-meta.schema.json, entities.yaml, relations.yaml, rules.yaml.
- Family README with dependency graph and quick start guide.
- Sloth-Eido Family Convention v1.4 compliance: all 12 skills pass audit (84 fixes applied).
