## 功能概览

OrgCOS AI 消费 API 标准化工具——从 OrgCOS 数据生成 OpenAPI 3.0 规范和 Python/TypeScript SDK。

## 快速开始

本技能为 OrgCOS 技能家族的组成部分，需配合 `orgcos-architect` 主控技能使用。

