## 功能概览

OrgCOS 全流程编排引擎——串联所有 orgcos-* 技能完成端到端构建，含技能调度、错误恢复、状态管理和飞书同步。

## 快速开始

本技能为 OrgCOS 技能家族的组成部分，需配合 `orgcos-architect` 主控技能使用。

```
# 通过 orgcos-architect 主控技能启动完整构建流程
用户: "帮我构建 OrgCOS"
```
