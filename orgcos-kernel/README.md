## 功能概览

OrgCOS T1 通用内核——定义组织认知操作系统不可修改的核心约束集，含 Schema 注册表、实体关系标准、治理引擎、跨层协调协议和 AI 消费 API 网关。

## 快速开始

本技能为 OrgCOS 技能家族的组成部分，需配合 `orgcos-architect` 主控技能使用。

```

```
