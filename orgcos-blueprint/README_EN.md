## Overview

OrgCOS T2 Industry Blueprint manager for loading, validating, and customizing industry preset packages. Manages industry-specific entity extensions, attribute extensions, governance parameter overrides, and domain-specific APIs via YAML blueprint files. Supports industry community contributions and version management. Use when the user mentions industry blueprint, manufacturing blueprint, financial blueprint, industry presets, or blueprint customization.
